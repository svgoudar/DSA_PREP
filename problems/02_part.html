Valid Anagram - #242#

Input

  • s: A string (e.g., "anagram")

  • t: Another string (e.g., "nagaram")

Output

  • Boolean value True if t is an anagram of s, else False

Example

Input: s = "anagram", t = "nagaram"
Output: True

Input: s = "rat", t = "car"
Output: False

Explanation: An Anagram is a word or phrase formed by rearranging the letters of a different word or phrase.
Solution Code 
class Solution(object):
    def isAnagram(self, s, t):
        """
        :type s: str
        :type t: str
        :rtype: bool
        """
        if len(s) != len(t):
            return False
        
        for i in set(s):
            if i not in t:
                return False
            if s.count(i) != t.count(i):
                return False
        return True
Complexity Analysis

  • Time Complexity: O(n)

  • Space Complexity: O(1)

Implement strStr() - #28#

Input

  • haystack: A string (e.g., "hello")

  • needle: A string to find within haystack (e.g., "ll")

Output

  • An integer representing the index of the first occurrence of needle in haystack, or -1 if not found.

Example

Input: haystack = "hello", needle = "ll"
Output: 2

Input: haystack = "aaaaa", needle = "bba"
Output: -1

Explanation: Return the index of the first occurrence of needle in haystack, or -1 if needle is not part of haystack.
Solution Code 
class Solution:
    def strStr(self, haystack, needle):
        for i in range(len(haystack) - len(needle) + 1):
            if haystack[i:i+len(needle)] == needle:
                return i
        return -1
Complexity Analysis

  • Time Complexity: O((n - m + 1) × m)

  • Space Complexity: O(1)

Reverse String - #344#

Input

  • s: List of characters (e.g., ["h","e","l","l","o"])

Output

  • The same list s should be modified in-place to reverse the characters.

Example

Input: s = ["h","e","l","l","o"]
Output: ["o","l","l","e","h"]

Explanation: Reverse the array of characters in-place.
Solution Code 
class Solution(object):
    def reverseString(self, s):
        """
        Do not return anything, modify s in-place instead.
        """
        left, right = 0, len(s) - 1
        while left < right:
            s[left], s[right] = s[right], s[left]
            left += 1
            right -= 1
Complexity Analysis

  • Time Complexity: O(n)

  • Space Complexity: O(1)

Goat Latin - #824#

Input

  • sentence: A string (e.g., "I speak Goat Latin")

Output

  • Transformed Goat Latin sentence

Example

Input: sentence = "I speak Goat Latin"
Output: "Imaa peaksmaaa oatGmaaaa atinLmaaaaa"

Explanation: Convert to Goat Latin: vowel words get "ma", consonant words move first letter to end + "ma", add 'a' per word index.
Solution Code 
class Solution(object):
    def toGoatLatin(self, S):
        """
        :type S: str
        :rtype: str
        """
        vowels = set('aeiouAEIOU')
        words = S.split()
        res = []
        for i, w in enumerate(words, 1):
            if w[0] in vowels:
                new = w + "ma"
            else:
                new = w[1:] + w[0] + "ma"
            new += "a" * i
            res.append(new)
        return " ".join(res)
Complexity Analysis

  • Time Complexity: O(n + k²)

  • Space Complexity: O(n + k²)

To Lower Case - #709#

Input

  • s: A string (e.g., "Hello")

  • Lowercase version of the string

Example

Input: s = "Hello"
Output: "hello"

Explanation: Convert all uppercase letters to lowercase.
Solution Code 
class Solution(object):
    def toLowerCase(self, s):
        """
        :type s: str
        :rtype: str
        """
        result = []
        for ch in s:
            if 'A' <= ch <= 'Z':
                result.append(chr(ord(ch) - ord('A') + ord('a')))
            else:
                result.append(ch)
        return "".join(result)

Count and Say - #38#

Input

  • n: Integer (e.g., 4)

Output

  • The nth string in the count-and-say sequence

Example

Input: n = 4
Output: "1211"

Explanation:
term1 = "1"
term2 = "11"       (one 1)
term3 = "21"       (two 1s)
term4 = "1211"     (one 2, one 1)
Solution Code 
class Solution(object):
    def countAndSay(self, n):
        """
        :type n: int
        :rtype: str
        """
        res = "1"
        for _ in range(1, n):
            prev = res
            res = ""
            count = 1
            for i in range(1, len(prev)):
                if prev[i] == prev[i - 1]:
                    count += 1
                else:
                    res += str(count) + prev[i - 1]
                    count = 1
            res += str(count) + prev[-1]
        return res
Complexity Analysis

  • Time Complexity: O(2ⁿ)

  • Space Complexity: O(2ⁿ)

Group Anagrams - #49#

Input

  • strs: List of lowercase strings (e.g., ["eat", "tea", "tan", "ate", "nat", "bat"])

Output

  • List of grouped anagrams

Example

Input: strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
Output: [["eat","tea","ate"], ["tan","nat"], ["bat"]]

Explanation: Group strings that are anagrams of each other.
Solution Code 
class Solution(object):
    def groupAnagrams(self, strs):
        """
        :type strs: List[str]
        :rtype: List[List[str]]
        """
        d = {}
        for s in strs:
            key = tuple(sorted(s))
            d.setdefault(key, []).append(s)
        return list(d.values())
Complexity Analysis

  • Time Complexity: O(N × K log K)

  • Space Complexity: O(NK)

Longest Substring Without Repeating Characters - #3#

Input

  • s: A string (e.g., "abcabcbb")

Output

  • Integer length of longest substring without repeating characters

Example

Input: s = "abcabcbb"
Output: 3

Explanation: The answer is "abc", with length 3.
Solution Code 
class Solution(object):
    def lengthOfLongestSubstring(self, s):
        """
        :type s: str
        :rtype: int
        """
        seen = {}
        left = res = 0
        for right, ch in enumerate(s):
            if ch in seen and seen[ch] >= left:
                left = seen[ch] + 1
            seen[ch] = right
            res = max(res, right - left + 1)
        return res
Complexity Analysis

  • Time Complexity: O(n)

  • Space Complexity: O(min(n, m))

Longest Palindromic Substring - #5#

Input

  • s: A string (e.g., "babad")

Output

  • The longest palindrome substring

Example

Input: s = "babad"
Output: "bab"

Explanation: "aba" is also a valid answer.
Solution Code 
class Solution(object):
    def longestPalindrome(self, s):
        """
        :type s: str
        :rtype: str
        """
        if len(s)<=1:
            return s

        dp= [[False]*len(s) for _ in range(len(s))]

        max_len=1
        start=0

        for i in range(len(s)):
            for j in range(i+1):
                if (s[i]==s[j]) and ((i-j+1<=2) or (dp[j+1][i-1])):
                    dp[j][i]=True

                    if (i-j+1 > max_len):
                        max_len=i-j+1
                        start=j
        return s[start:start+max_len]
Complexity Analysis

  • Time Complexity: O(n²)

  • Space Complexity: O(n²)

Permutation in String - #567#

Problem

Given strings s1 and s2, return true if s2 contains a permutation of s1.

Input

  • s1: string

  • s2: string

Output

  • Boolean value

Example

Input: s1 = "ab", s2 = "eidbaooo"
Output: True
Solution Code 
class Solution(object):
    def checkInclusion(self, s1, s2):
        from collections import Counter
        need = Counter(s1)
        window = {}
        l = 0
        for r, ch in enumerate(s2):
            window[ch] = window.get(ch,0)+1
            while window[ch] > need.get(ch,0):
                window[s2[l]] -=1
                l+=1
            if r-l+1 == len(s1):
                return True
        return False

Remove All Adjacent Duplicates in String II - #1209#

🧾 Problem

Given string s and integer k, repeatedly remove adjacent duplicate characters of length k until no more.

🔢 Input

  • s: string

  • k: int

📤 Output

  • The final string after all removals.

✅ Example

Input: s = "deeedbbcccbdaa", k = 3
Output: "aa"
🧠 Solution Code 
class Solution(object):
    def removeDuplicates(self, s, k):
        """
        :type s: str
        :type k: int
        :rtype: str
        """
        stack = []  # Each element is [char, count]

        for char in s:
            if stack and stack[-1][0] == char:
                stack[-1][1] += 1  # increment count
                if stack[-1][1] == k:
                    stack.pop()  # remove the group
            else:
                stack.append([char, 1])  # new char, count = 1

        # Reconstruct string from stack
        return ''.join(char * count for char, count in stack)
🧮 Complexity Analysis

  • Time Complexity: O(n)

  • Space Complexity: O(n)

Multiply Strings - #43#

🧾 Problem

Given two non-negative integers num1 and num2 as strings, return the product also as a string.

🔢 Input

  • num1: string

  • num2: string

📤 Output

  • Product as string.

✅ Example

Input: num1 = "123", num2 = "456"
Output: "56088"
🧠 Solution Code 
class Solution(object):
    def multiply(self, num1, num2):
        m, n = len(num1), len(num2)
        res = [0]*(m+n)
        for i in reversed(range(m)):
            for j in reversed(range(n)):
                mul = int(num1[i])*int(num2[j])
                sum_ = mul + res[i+j+1]
                res[i+j+1] = sum_ %10
                res[i+j] += sum_//10
        # skip leading zeros
        idx = 0
        while idx<len(res)-1 and res[idx]==0:
            idx+=1
        return ''.join(map(str,res[idx:]))

Word Pattern - #290#

🧾 Problem

Given a pattern and a string s, return true if s follows the same pattern.

🔢 Input

  • pattern: string

  • s: string of words

📤 Output

  • Boolean value

✅ Example

Input: pattern = "abba", s = "dog cat cat dog"
Output: True
🧠 Solution Code 
class Solution(object):
    def wordPattern(self, pattern, s):
        """
        :type pattern: str
        :type s: str
        :rtype: bool
        """
        words = s.split()
        if len(pattern) != len(words):
            return False
        mp, used = {}, set()
        for c, w in zip(pattern, words):
            if c in mp:
                if mp[c] != w:
                    return False
            else:
                if w in used:
                    return False
                mp[c] = w
                used.add(w)
        return True
🧮 Complexity Analysis

  • Time Complexity: O(n)

  • Space Complexity: O(n)

Custom Sort String - #791#

Problem

Given order string order (a permutation of lowercase letters) and string s, sort the characters in s so that they match the order defined by order. Characters not in order go at the end.

Input

  • order: string

  • s: string

📤 Output

  • Sorted version of s

Example

Input: order = "cba", s = "abcd"
Output: "cbad"
🧠 Solution Code 
class Solution(object):
    def customSortString(self, order, s):
        """
        :type order: str
        :type s: str
        :rtype: str
        """
        count = {}
        for ch in s:
            count[ch] = count.get(ch,0) +1
        res = []
        for ch in order:
            res.append(ch * count.pop(ch,0))
        for ch, cnt in count.items():
            res.append(ch * cnt)
        return "".join(res)
🧮 Complexity Analysis

  • Time Complexity: O(n + m) where n = len(order), m = len(s)

  • Space Complexity: O(m)

Wildcard Matching - #44#

🧾 Problem

Given strings s and pattern p where p includes ‘?’ and ‘*’ wildcard characters, implement wildcard matching.

  • ‘?’ matches any single character.

  • ‘*’ matches any sequence of characters (including empty).

Return true if s matches the pattern.

🔢 Input

  • s: Target string

  • p: Pattern string with wildcards

📤 Output

  • Boolean value whether s matches p

✅ Example

Input: s = "adceb", p = "*a*b"
Output: True

Input: s = "acdcb", p = "a*c?b"
Output: False
🧠 Solution Code (DP) 
class Solution(object):
    def isMatch(self, s, p):
        m, n = len(s), len(p)
        dp = [[False]*(n+1) for _ in range(m+1)]
        dp[0][0] = True
        for j in range(1, n+1):
            if p[j-1] == '*':
                dp[0][j] = dp[0][j-1]
        for i in range(1, m+1):
            for j in range(1, n+1):
                if p[j-1] == s[i-1] or p[j-1] == '?':
                    dp[i][j] = dp[i-1][j-1]
                elif p[j-1] == '*':
                    dp[i][j] = dp[i][j-1] or dp[i-1][j]
        return dp[m][n]
🧮 Complexity Analysis

  • Time Complexity: O(mn)

  • Space Complexity: O(mn) (can optimize to O(n))

Regular Expression Matching - #10#

🧾 Problem

Implement regex matching with support for ‘.’ and ‘*’:

  • ‘.’ matches any single character.

  • ‘*’ matches zero or more of the preceding element.

Return true if text matches pattern.

🔢 Input

  • text: Target string

  • pattern: Regex pattern

📤 Output

  • Boolean value

✅ Example

Input: text = "aab", pattern = "c*a*b"
Output: True

Input: text = "mississippi", pattern = "mis*is*p*."
Output: False
🧠 Solution Code (DP) 

# Top Down aproach / Memoization

class Solution(object):
    def isMatch(self, s, p):
        # Create a memoization dictionary to store results of subproblems
        memo = {}
        # Define a helper function for recursion with indices i (for s) and j (for p)
        def dp(i, j):
            # If result is already computed, return from memo
            if (i, j) in memo:
                return memo[(i, j)]
            # If we've reached the end of the pattern
            if j == len(p):
                # Return True if s is also fully matched
                ans = i == len(s)
            else:
                # Check if the current character matches (if s is not exhausted)
                first_match = i < len(s) and (p[j] == s[i] or p[j] == '.')
                # If next character in p is '*', we have two choices:
                if (j + 1) < len(p) and p[j + 1] == '*':
                    # 1. Don't use the star (move p by 2)
                    #2. Use the star if first_match (move s by 1, keep p)
                    ans = dp(i, j + 2) or (first_match and dp(i + 1, j))
                else:
                    # If not '*', proceed only if first_match, move both by 1
                    ans = first_match and dp(i + 1, j + 1)
            # Store result in memo and return
            memo[(i, j)] = ans
            return ans
        # Start recursion from the beginning of s and p
        return dp(0, 0)
🧮 Complexity Analysis

  • Time Complexity: O(mn)

  • Space Complexity: O(mn)

Minimum Window Substring - #76#

🧾 Problem

Given strings s and t, return the minimum window in s which contains all characters of t. Return empty string if no such window.

🔢 Input

  • s: Target string

  • t: Pattern string

📤 Output

  • Smallest substring of s containing all chars of t

✅ Example

Input: s = "ADOBECODEBANC", t = "ABC"
Output: "BANC"
🧠 Solution Code (Sliding Window) 
class Solution(object):
    def minWindow(self, s, t):
        from collections import Counter
        need, window = Counter(t), {}
        have, needCount = 0, len(need)
        res = ""
        l = 0
        for r in range(len(s)):
            c = s[r]
            window[c] = window.get(c, 0) + 1
            if c in need and window[c] == need[c]:
                have += 1
            while have == needCount:
                substring = s[l:r+1]
                if not res or len(substring) < len(res):
                    res = substring
                window[s[l]] -= 1
                if s[l] in need and window[s[l]] < need[s[l]]:
                    have -= 1
                l += 1
        return res
🧮 Complexity Analysis

  • Time Complexity: O(n + m)

  • Space Complexity: O(n + |Σ|)

Palindrome Pairs - #336#

🧾 Problem

Given a list of unique words, return all pairs [i, j] such that words[i] + words[j] forms a palindrome.

🔢 Input

  • words: List of unique strings

📤 Output

  • List of index pairs [i, j]

✅ Example

Input: words = ["bat","tab","cat"]
Output: [[0,1],[1,0]]
🧠 Solution Code (Trie + Palindrome Checks) 
class Solution(object):
    def palindromePairs(self, words):
        def is_pal(s):
            return s == s[::-1]
        trie = {}
        for i, w in enumerate(words):
            node = trie
            for j, ch in enumerate(reversed(w)):
                if is_pal(w[:len(w)-j]):
                    node.setdefault('pal', []).append(i)
                node = node.setdefault(ch, {})
            node['idx'] = i
        res = []
        for i, w in enumerate(words):
            node = trie
            for j, ch in enumerate(w):
                if 'idx' in node and node['idx'] != i and is_pal(w[j:]):
                    res.append([i, node['idx']])
                if ch not in node:
                    break
                node = node[ch]
            else:
                for j in node.get('pal', []):
                    if i != j:
                        res.append([i, j])
        return res
🧮 Complexity Analysis

  • Time Complexity: O(k²*N + Σk) where k = avg length

  • Space Complexity: O(Nk)

Word Ladder II - #126#

🧾 Problem

Given beginWord, endWord, and wordList, return all shortest transformation sequences from beginWord to endWord, where each step changes one letter and the word must be in the wordList.

🔢 Input

  • beginWord, endWord: strings

  • wordList: list of strings

📤 Output

  • List of lists, each representing a shortest transformation chain

✅ Example

Input: beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log","cog"]
Output: [
  ["hit","hot","dot","dog","cog"],
  ["hit","hot","lot","log","cog"]
]
🧠 Solution Code (BFS + DFS) 
class Solution:
    def findLadders(self, beginWord, endWord, wordList):
        prefix_d = defaultdict(list)
        for word in wordList:
            for i in range(0,len(word)):
                prefix_d[word[0:i]+"*"+word[i+1:]].append(word)
        
        order = {beginWord: []}
        queue = deque([beginWord])
        temp_q = deque()
        go_on = True
        end_list = []
        
        while queue and go_on:  # There is no node even added to temp_q
            temp_d = {}
            while queue:        # Pop every node on this level
                cur = queue.popleft()
                for i in range(0, len(cur)):
                    for j in prefix_d[cur[0:i]+"*"+cur[i+1:]]:
                        if j == endWord:
                            end_list.append(j)
                            go_on = False
                        if j not in order:
                            if j not in temp_d:
                                temp_d[j] = [cur]
                                temp_q.append(j)
                            else:
                                temp_d[j].append(cur)
            queue = temp_q
            temp_q = deque()
            order.update(temp_d)
        
        ret = []
        
        # DFS to restore the paths
        def dfs(path, node):
            path = path + [node]    # add the node(Deepcopy)
            if order[node] == []:
                ret.append(list(path[::-1]))
                return
            for i in order[node]:
                dfs(path, i)
        if endWord in order:
            dfs([], endWord)
        else:
            return []
        
        return ret
🧮 Complexity Analysis

  • Time Complexity: Roughly O(N * 26^L)

  • Space Complexity: Proportional to number of paths

Basic Calculator - #224#

Problem

Implement a basic calculator to evaluate a string expression containing +, -, (, ), and digits. No multiplication/division.

Input

  • s: Arithmetic expression (e.g., "(1+(4+5+2)-3)+(6+8)")

Output

  • Integer result

Example

Input: s = "(1+(4+5+2)-3)+(6+8)"
Output: 23
🧠 Solution Code (Stack) 
class Solution(object):
    def calculate(self, s):
        res, num, sign = 0, 0, 1
        stack = []
        for c in s:
            if c.isdigit():
                num = num*10 + int(c)
            elif c in '+-':
                res += sign*num
                num = 0
                sign = 1 if c=='+' else -1
            elif c == '(':
                stack.append(res)
                stack.append(sign)
                res, sign = 0, 1
            elif c == ')':
                res += sign*num
                num = 0
                res *= stack.pop()
                res += stack.pop()
        res += sign*num
        return res
🧮 Complexity Analysis

  • Time Complexity: O(n)

  • Space Complexity: O(n)

Remove Invalid Parentheses - #301#

Problem

Remove the minimum number of invalid parentheses to make the input string valid. Return all possible valid expressions.

Input

  • s: String containing parentheses and letters

Output

  • List of all valid strings after removals

Example

Input: s = "()())()"
Output: ["()()()", "(())()"]
🧠 Solution Code (BFS) 
class Solution(object):
    def removeInvalidParentheses(self, s):
        def is_valid(st):
            bal = 0
            for c in st:
                if c=='(':
                    bal+=1
                elif c==')':
                    bal-=1
                    if bal<0:
                        return False
            return bal==0
        
        level = {s}
        while True:
            valid = [st for st in level if is_valid(st)]
            if valid:
                return valid
            next_level = set()
            for st in level:
                for i in range(len(st)):
                    if st[i] in '()':
                        next_level.add(st[:i] + st[i+1:])
            level = next_level
🧮 Complexity Analysis

  • Time Complexity: Exponential in worst case

  • Space Complexity: Exponential

Scramble String - #87#

Problem

Given a string s1, determine if s2 is a scramble of s1. Scrambling involves recursively partitioning and swapping.

Input

  • s1, s2: Strings of equal length

Output

  • Boolean value

Example

Input: s1 = "great", s2 = "rgeat"
Output: True
🧠 Solution Code (Recursive + Memo) 
class Solution(object):
    def isScramble(self, s1, s2, memo={}):
        if s1==s2:
            return True
        if (s1,s2) in memo:
            return memo[(s1,s2)]
        if sorted(s1)!=sorted(s2):
            return False
        n = len(s1)
        for i in range(1, n):
            if (self.isScramble(s1[:i], s2[:i], memo) and
                self.isScramble(s1[i:], s2[i:], memo)) or \
               (self.isScramble(s1[:i], s2[n-i:], memo) and
                self.isScramble(s1[i:], s2[:n-i], memo)):
                memo[(s1,s2)] = True
                return True
        memo[(s1,s2)] = False
        return False
🧮 Complexity Analysis

  • Time Complexity: Very high (exponential with memo helps)

  • Space Complexity: O(n⁴) in worst case

Distinct Subsequences - #115#

Problem

Given strings s and t, count the number of distinct subsequences of s which equal t.

Input

  • s, t: Strings

Output

  • Integer count of subsequences

Example

Input: s = "rabbbit", t = "rabbit"
Output: 3
🧠 Solution Code (DP) 
class Solution(object):
    def numDistinct(self, s, t):
        m, n = len(s), len(t)
        dp = [[0]*(n+1) for _ in range(m+1)]
        for i in range(m+1):
            dp[i][0] = 1
        for i in range(1, m+1):
            for j in range(1, n+1):
                dp[i][j] = dp[i-1][j]
                if s[i-1] == t[j-1]:
                    dp[i][j] += dp[i-1][j-1]
        return dp[m][n]
🧮 Complexity Analysis

  • Time Complexity: O(mn)

  • Space Complexity: O(mn)

Data Stream as Disjoint Intervals - #352#

Problem

Maintain a data structure that supports:

  • addNum(val): add value from data stream,

  • getIntervals(): return disjoint intervals of added values.

Input

  • Sequence of addNum calls, then getIntervals

Output

  • List of disjoint intervals

Example

addNum(1)
addNum(3)
addNum(7)
getIntervals() -> [[1,1],[3,3],[7,7]]
addNum(2)
getIntervals() -> [[1,3],[7,7]]
🧠 Solution Code (SortedList) 
from bisect import bisect_left
class SummaryRanges(object):
    def __init__(self):
        self.intervals = []
    def addNum(self, val):
        i = bisect_left(self.intervals, [val, val])
        start, end = val, val
        while i < len(self.intervals) and self.intervals[i][0] <= end + 1:
            start = min(start, self.intervals[i][0])
            end = max(end, self.intervals[i][1])
            self.intervals.pop(i)
        self.intervals.insert(i, [start, end])
    def getIntervals(self):
        return self.intervals
🧮 Complexity Analysis

  • Time Complexity: O(n) per insertion in worst case

  • Space Complexity: O(n)
