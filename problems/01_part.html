Two Sum - #1#

Input

  • nums: List of integers (e.g., [2, 7, 11, 15])

  • target: Integer (e.g., 9)

Output

  • A list of two indices [i, j] such that:

    nums[i] + nums[j] == target

Example

Input: nums = [2, 7, 11, 15], target = 9  
Output: [0, 1]

Explanation: nums[0] + nums[1] = 2 + 7 = 9
Solution Code 
  class Solution:
      def twoSum(self, nums: List[int], target: int) -> List[int]:
          has = {}
          for i, num in enumerate(nums):
              if target - num in has:
                  return has[target - num], i
              has[num] = i
Complexity Analysis

  • Time Complexity: O(n) — single pass through the list, dictionary lookups are O(1) average

  • Space Complexity: O(n) — dictionary stores at most n elements

Remove Duplicates from Sorted Array - #26#

Input

  • nums: Sorted list of integers (e.g., [1,1,2])

Output

  • Return the new length after removing duplicates in-place, with unique elements at the start.

Example

Input: nums = [1,1,2]
Output: 2  
Modified nums = [1,2,...]

Explanation: The first two elements after modification are unique.
Solution Code 
class Solution:
    def removeDuplicates(self, nums: List[int]) -> int:
        if not nums:
            return 0
        i = 0
        for j in range(1, len(nums)):
            if nums[j] != nums[i]:
                i += 1
                nums[i] = nums[j]
        return i + 1
Complexity Analysis

  • Time Complexity: O(n) — single pass

  • Space Complexity: O(1) — in-place

Best Time to Buy and Sell Stock - #121#

Input

  • prices: List of integers representing the stock price on each day (e.g., [7,1,5,3,6,4])

Output

  • Maximum profit possible from a single buy-sell transaction.

Example

Input: prices = [7,1,5,3,6,4]
Output: 5

Explanation: Buy on day 2 (price = 1), sell on day 5 (price = 6), profit = 6 - 1 = 5
Solution Code 
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        min_price = float('inf')
        max_profit = 0
        for price in prices:
            if price < min_price:
                min_price = price
            elif price - min_price > max_profit:
                max_profit = price - min_price
        return max_profit
Complexity Analysis

  • Time Complexity: O(n)

  • Space Complexity: O(1)

Merge Sorted Array - #88#

Input

  • nums1: First sorted list with extra space (e.g., [1,2,3,0,0,0])

  • m: Number of valid elements in nums1

  • nums2: Second sorted list (e.g., [2,5,6])

  • n: Number of elements in nums2

Output

  • Merged sorted array in nums1 in-place.

Example

Input: nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3
Output: [1,2,2,3,5,6]

Explanation: The final sorted array should not be returned by the function, but instead be stored inside the array nums1.
Solution Code 
class Solution:
    def merge(self, nums1: List[int], m: int, nums2: List[int], n: int) -> None:
        i, j, k = m - 1, n - 1, m + n - 1
        while i >= 0 and j >= 0:
            if nums1[i] > nums2[j]:
                nums1[k] = nums1[i]
                i -= 1
            else:
                nums1[k] = nums2[j]
                j -= 1
            k -= 1
        while j >= 0:
            nums1[k] = nums2[j]
            j -= 1
            k -= 1
Complexity Analysis

  • Time Complexity: O(m + n)

  • Space Complexity: O(1)

Move Zeroes - #283#

Input

  • nums: List of integers with zeroes (e.g., [0,1,0,3,12])

Output

  • Rearranged list where all 0s are moved to the end, maintaining the order of non-zero elements.

Example

Input: nums = [0,1,0,3,12]
Output: [1,3,12,0,0]
Solution Code 
class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        insert_pos = 0
        for num in nums:
            if num != 0:
                nums[insert_pos] = num
                insert_pos += 1
        while insert_pos < len(nums):
            nums[insert_pos] = 0
            insert_pos += 1
Complexity Analysis

  • Time Complexity: O(n)

  • Space Complexity: O(1)

Valid Mountain Array - #941#

Input

  • arr: List of integers representing elevation (e.g., [0,3,2,1])

Output

  • Boolean indicating whether it’s a valid mountain array.

Example

Input: arr = [0,3,2,1]
Output: True

Explanation: Strictly increasing then strictly decreasing.
Solution Code 
class Solution:
    def validMountainArray(self, arr: List[int]) -> bool:
        if len(arr) < 3: return False
        l = 0
        r = len(arr) - 1
        while l + 1 < len(arr) - 1 and arr[l] < arr[l + 1]: 
            l += 1
        while r - 1 > 0 and arr[r] < arr[r - 1]: 
            r -= 1
        return l == r
Complexity Analysis

  • Time Complexity: O(n)

Third Maximum Number - #414#

Input

  • nums: List of integers (e.g., [3,2,1])

Output

  • The third distinct maximum number. If it does not exist, return the maximum number.

Example

Input: nums = [3,2,1]
Output: 1

Explanation: Third distinct max is 1
Solution Code 
class Solution:
    def thirdMax(self, nums: List[int]) -> int:
        first = second = third = float("-inf")

        for num in nums:
            
            if num in (first,second,third):
                continue
            if num > first:
                first,second,third =num,first,second
            elif num > second:
                second,third = num,second
            elif num > third:
                third = num
        return third if third != float("-inf") else first
Complexity Analysis

  • Time Complexity: O(n)

  • Space Complexity: O(1)

Output: 6

    def maxSubArray(self, nums: List[int]) -> int:
        max_sum = cur_sum = nums[0]
        for n in nums[1:]:
            cur_sum = max(n, cur_sum + n)

Output: 2

class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        count = 0
        candidate = None
        for num in nums:
            if count == 0:
                candidate = num

        return candidate

Intersection of Two Arrays II - #350#

Input

  • nums1, nums2: Lists of integers

Output

  • An array of their intersection (elements must appear as many times as they appear in both arrays)

Example

Input: nums1 = [4,9,5], nums2 = [9,4,9,8,4]
Output: [4,9]
Solution Code 
from collections import Counter

class Solution:
    def intersect(self, nums1: List[int], nums2: List[int]) -> List[int]:
        count1 = Counter(nums1)
        result = []
        for num in nums2:
            if count1[num] > 0:
                result.append(num)
                count1[num] -= 1
        return result
Complexity Analysis

  • Time Complexity: O(n + m)

  • Space Complexity: O(min(n, m))

3Sum - #15#

Input

  • nums: List of integers (e.g., [-1,0,1,2,-1,-4])

Output

  • All unique triplets [nums[i], nums[j], nums[k]] such that they sum to 0.

Example

Input: nums = [-1,0,1,2,-1,-4]
Output: [[-1,-1,2],[-1,0,1]]
Solution Code 
class Solution:
    def threeSum(self, nums):
        """
        :type nums: List[int]
        :rtype: List[List[int]]
        """
        final = []
        nums = sorted(nums)
        i=0
        while ( i < len(nums)-1 ):
            a = nums[i]
            b = i+1
            c = len(nums)-1

            while b<c:
                if a+nums[b]+nums[c] == 0:
                    final.append([a,nums[b],nums[c]])
                    b+=1
                    while b<c:
                        if nums[b]==nums[b-1]:
                            b+=1
                        else:
                            break
                elif a+nums[b]+nums[c] > 0:
                    c-=1
                elif a+nums[b]+nums[c] < 0:
                    b+=1

            while i < len(nums)-1:
                if nums[i]==nums[i+1]:
                    i+=1
                else:
                    break
            i+=1
        return final
Complexity Analysis

  • Time Complexity: O(n²)

  • Space Complexity: O(1) (excluding output)

Container With Most Water - #11#

Input

  • height: List of non-negative integers representing vertical lines

Output

  • Maximum area of water a container can store.

Example

Input: height = [1,8,6,2,5,4,8,3,7]
Output: 49

Explanation: The above vertical lines are represented by array [1,8,6,2,5,4,8,3,7]. 
In this case, the max area of water (blue section) the container can contain is 49.

Solution Code 
class Solution:
    def maxArea(self, height: List[int]) -> int:
        left, right = 0, len(height) - 1
        max_area = 0
        while left < right:
            width = right - left
            max_area = max(max_area, width * min(height[left], height[right]))
            if height[left] < height[right]:
                left += 1
            else:
                right -= 1
        return max_area
Complexity Analysis

  • Time Complexity: O(n)

  • Space Complexity: O(1)

Product of Array Except Self - #238#

Input

  • nums: List of integers (e.g., [1,2,3,4])

Output

  • A list where each element is the product of all other elements except itself.

Example

Input: nums = [1,2,3,4]
Output: [24,12,8,6]
Solution Code 
class Solution(object):
    def productExceptSelf(self, nums):
        total_product = 1
        zero_count = 0
        
        for num in nums:
            if num != 0:
                total_product *= num
            else:
                zero_count += 1
                
        result = []
        
        if zero_count > 1:
            return [0] * len(nums)
        
        for num in nums:
            if num != 0:
                if zero_count == 1:
                    result.append(0)
                else:
                    result.append(total_product // num)
            else:
                result.append(total_product)
        
        return result
Complexity Analysis

  • Time Complexity: O(n)

  • Space Complexity: O(1) (excluding output)

Set Matrix Zeroes - #73#

Input

  • matrix: 2D list of integers

Output

  • Modify matrix in-place to set entire row and column to 0 if an element is 0.

Example

Input: matrix = [[1,1,1],[1,0,1],[1,1,1]]
Output: [[1,0,1],[0,0,0],[1,0,1]]
Solution Code 
class Solution:
    def setZeroes(self, matrix: List[List[int]]) -> None:
        """
        Do not return anything, modify matrix in-place instead.
        """
        if not matrix:
            return []

        m = len(matrix)
        n = len(matrix[0])

        zeroes_row = [False] * m
        zeroes_col = [False] * n
        for row in range(m):
            for col in range(n):
                if matrix[row][col] == 0:
                    zeroes_row[row] = True
                    zeroes_col[col] = True

        for row in range(m):
            for col in range(n):
                if zeroes_row[row] or zeroes_col[col]:
                    matrix[row][col] = 0
        return matrix
Complexity Analysis

  • Time Complexity: O(m × n)

  • Space Complexity: O(m + n)

Subarray Sum Equals K - #560#

Input

  • nums: List of integers

  • k: Integer

Output

  • Return the total number of continuous subarrays whose sum equals k.

Example

Input: nums = [1,1,1], k = 2
Output: 2
Solution Code 
class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        count = 0
        current_sum = 0
        prefix_sums = {0: 1}
        for num in nums:
            current_sum += num
            count += prefix_sums.get(current_sum - k, 0)
            prefix_sums[current_sum] = prefix_sums.get(current_sum, 0) + 1
        return count
Complexity Analysis

  • Time Complexity: O(n)

  • Space Complexity: O(n)

Spiral Matrix - #54#

Input

  • matrix: 2D list of integers

Output

  • Return all elements of the matrix in spiral order.

Example

Input: matrix = [[1,2,3],[4,5,6],[7,8,9]]
Output: [1,2,3,6,9,8,7,4,5]
Solution Code 
class Solution(object):
    def spiralOrder(self, matrix):
        """
        :type matrix: List[List[int]]
        :rtype: List[int]
        """
        left,right = 0,len(matrix[0]) -1
        top,bottom = 0,len(matrix) -1
        lis = []
        while left <= right and top <= bottom:
            for i in range(left,right+1):
                lis.append(matrix[top][i])
            top +=1

            for i in range(top,bottom +1):
                lis.append(matrix[i][right])
            right -= 1

            if top <= bottom:
                for  i in range(right,left-1,-1):
                    lis.append(matrix[bottom][i])
                bottom -= 1

            if left <= right:
                for i in range(bottom,top-1,-1):
                    lis.append(matrix[i][left])
                left +=1
            
        return lis
Complexity Analysis

  • Time Complexity: O(m × n)

  • Space Complexity: O(1) (excluding output)

Sort Colors (Dutch National Flag) - #75#

Input

  • nums: List of integers with values 0, 1, or 2

Output

  • Sort the array in-place so that elements of the same color are adjacent and in the order 0, 1, 2.

Example

Input: nums = [2,0,2,1,1,0]
Output: [0,0,1,1,2,2]
Solution Code 
class Solution:
    def sortColors(self, nums: List[int]) -> None:
        low, mid, high = 0, 0, len(nums) - 1
        while mid <= high:
            if nums[mid] == 0:
                nums[low], nums[mid] = nums[mid], nums[low]
                low += 1
                mid += 1
            elif nums[mid] == 1:
                mid += 1
            else:
                nums[mid], nums[high] = nums[high], nums[mid]
                high -= 1
        return nums
Complexity Analysis

  • Time Complexity: O(n)

  • Space Complexity: O(1)

Insert Interval - #57#

Input

  • intervals: List of intervals sorted by start time

  • newInterval: Interval to insert

Output

  • Merge newInterval and return the new list of intervals.

Example

Input: intervals = [[1,3],[6,9]], newInterval = [2,5]
Output: [[1,5],[6,9]]
Solution Code 
class Solution:
    def insert(self, intervals: List[List[int]], newInterval: List[int]) -> List[List[int]]:
        res = []
        for i in intervals:
            if i[1] < newInterval[0]:
                res.append(i)
            elif newInterval[1] < i[0]:
                res.append(newInterval)
                newInterval = i
            else:
                newInterval[0] = min(newInterval[0], i[0])
                newInterval[1] = max(newInterval[1], i[1])
        res.append(newInterval)
        return res
Complexity Analysis

  • Time Complexity: O(n)

  • Space Complexity: O(n)

Maximum Product Subarray - #152#

Input

  • nums: List of integers

Output

  • Return the maximum product of a contiguous subarray.

Example

Input: nums = [2,3,-2,4]
Output: 6
Solution Code 
class Solution(object):
    def maxProduct(self, nums):
        """
        :type nums: List[int]
        :rtype: int
        """
        # traverse from L and R with kadane's algorithm
        # have to avoid odd -ve element from either ends
        max_pro = float("-inf")
        curr_l = curr_r = 1
        n = len(nums)
        for i in range(n):
            if curr_l == 0:
                curr_l = 1
            if curr_r == 0:
                curr_r = 1
            curr_l *= nums[i]
            curr_r *= nums[n-1 -i]
            max_pro = max(curr_l, curr_r, max_pro)
        return max_pro
Complexity Analysis

  • Time Complexity: O(n)

  • Space Complexity: O(1)

Remove Duplicates from Sorted Array II - #80#

Input

  • nums: A sorted list of integers (e.g., [1,1,1,2,2,3])

Output

  • Return the new length after removing extra duplicates (more than twice) in-place, such that each unique element appears at most twice.

Example

Input: nums = [1,1,1,2,2,3]
Output: 5  
Modified nums = [1,1,2,2,3,_]

Explanation: The first five elements are the required result. Only up to two duplicates of each number are allowed.
Solution Code 
class Solution:
    def removeDuplicates(self, nums: List[int]) -> int:
        if len(nums) <= 2:
            return len(nums)

        insert_pos = 2
        for i in range(2, len(nums)):
            if nums[i] != nums[insert_pos - 2]:
                nums[insert_pos] = nums[i]
                insert_pos += 1

        return insert_pos
Complexity Analysis

  • Time Complexity: O(n)

  • Space Complexity: O(1)

Longest Substring Without Repeating Characters - #3#

Input

  • s: A string

Output

  • Length of the longest substring without repeating characters

Example

Input: s = "abcabcbb"
Output: 3
Solution Code 
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        char_set = set()
        left = max_len = 0
        for right in range(len(s)):
            while s[right] in char_set:
                char_set.remove(s[left])
                left += 1
            char_set.add(s[right])
            max_len = max(max_len, right - left + 1)
        return max_len
Complexity Analysis

  • Time Complexity: O(n)

  • Space Complexity: O(k) where k is the charset size

Merge Intervals - #56#

Input

  • intervals: List of intervals

Output

  • Merged list of intervals

Example

Input: intervals = [[1,3],[2,6],[8,10],[15,18]]
Output: [[1,6],[8,10],[15,18]]
Solution Code 
class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        intervals.sort()
        merged = [intervals[0]]
        for start, end in intervals[1:]:
            last_end = merged[-1][1]
            if start <= last_end:
                merged[-1][1] = max(last_end, end)
            else:
                merged.append([start, end])
        return merged
Complexity Analysis

  • Time Complexity: O(n log n)

  • Space Complexity: O(n)

Search in Rotated Sorted Array - #33#

Input

  • nums: Rotated sorted array

  • target: Target value

Output

  • Index of target if found, else -1

Example

Input: nums = [4,5,6,7,0,1,2], target = 0
Output: 4
Solution Code 
class Solution:
    def search(self, nums: List[int], target: int) -> int:
        low, high = 0, len(nums) - 1
        while low <= high:
            mid = (low + high) // 2
            if nums[mid] == target:
                return mid
            if nums[low] <= nums[mid]:  # Left half is sorted
                if nums[low] <= target < nums[mid]:
                    high = mid - 1
                else:
                    low = mid + 1
            else:  # Right half is sorted
                if nums[mid] < target <= nums[high]:
                    low = mid + 1
                else:
                    high = mid - 1
        return -1
Complexity Analysis

  • Time Complexity: O(log n)

  • Space Complexity: O(1)

Rotate Image - #48#

Input

  • matrix: A n x n 2D matrix representing an image

Output

  • Rotate the image 90 degrees clockwise in-place

Example

Input: matrix = [[1,2,3],[4,5,6],[7,8,9]]
Output: [[7,4,1],[8,5,2],[9,6,3]]
Solution Code 
class Solution:
    def rotate(self, matrix: List[List[int]]) -> None:
        n = len(matrix)
        for i in range(n):
            for j in range(i, n):
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
        for row in matrix:
            row.reverse()
Complexity Analysis

  • Time Complexity: O(n²)

  • Space Complexity: O(1)

Combination Sum - #39#

Input

  • candidates: List of positive integers (distinct)

  • target: Target sum

Output

  • All unique combinations where chosen numbers sum to target (can reuse same number)

Example

Input: candidates = [2,3,6,7], target = 7
Output: [[2,2,3],[7]]
Solution Code 
class Solution:
    def combinationSum(self, candidates: List[int], target: int) -> List[List[int]]:
        res = []

        def backtrack(start, path, total):
            if total == target:
                res.append(path[:])
                return
            if total > target:
                return
            for i in range(start, len(candidates)):
                path.append(candidates[i])
                backtrack(i, path, total + candidates[i])
                path.pop()

        backtrack(0, [], 0)
        return res
Complexity Analysis

  • Time Complexity: O(2^n) worst case

  • Space Complexity: O(n) recursion stack

First Missing Positive - #41#

Input

  • nums: List of integers

Output

  • Smallest missing positive integer

Example

Input: nums = [3, 4, -1, 1]
Output: 2
Solution Code 
class Solution:
    def firstMissingPositive(self, nums: List[int]) -> int:
        # Function to swap elements in the array
        def swap(arr, i, j):
            arr[i], arr[j] = arr[j], arr[i]
        
        n = len(nums)
        
        # Place each positive integer i at index i-1 if possible
        for i in range(n):
            while 0 < nums[i] <= n and nums[i] != nums[nums[i] - 1]:
                swap(nums, i, nums[i] - 1)
        
        # Find the first missing positive integer
        for i in range(n):
            if nums[i] != i + 1:
                return i + 1
        
        # If all positive integers from 1 to n are present, return n + 1
        return n + 1
Complexity Analysis

  • Time Complexity: O(n)

  • Space Complexity: O(1)

Trapping Rain Water - #42#

Input

  • height: List of non-negative integers

Output

  • Total amount of trapped water

Example

Input: height = [0,1,0,2,1,0,1,3,2,1,2,1]
Output: 6
Solution Code 
class Solution:
    def trap(self, height):
        left, right = 0, len(height) - 1
        left_max = right_max = 0
        res = 0
        while left < right:
            if height[left] < height[right]:
                if height[left] >= left_max:
                    left_max = height[left]
                else:
                    res += left_max - height[left]
                left += 1
            else:
                if height[right] >= right_max:
                    right_max = height[right]
                else:
                    res += right_max - height[right]
                right -= 1
        return res
Complexity Analysis

  • Time Complexity: O(n)

  • Space Complexity: O(1)

class Solution(object):

        """
        :type nums: List[int]
        :rtype: int
        """
        nums = sorted(list(set(nums)))
        if len(nums) < 2:
            return 0
        
        return max(abs(nums[i-1] - nums[i]) for i in range(1, len(nums)))

Sliding Window Maximum - #239#

Input

  • nums: List of integers

  • k: Size of the window

Output

  • Maximum of each sliding window

Example

Input: nums = [1,3,-1,-3,5,3,6,7], k = 3
Output: [3,3,5,5,6,7]
Solution Code 
from collections import deque

class Solution:
    def maxSlidingWindow(self, nums, k):
        q = deque()
        res = []
        for i in range(len(nums)):
            while q and q[0] < i - k + 1:
                q.popleft()
            while q and nums[q[-1]] < nums[i]:
                q.pop()
            q.append(i)
            if i >= k - 1:
                res.append(nums[q[0]])
        return res
Complexity Analysis

  • Time Complexity: O(n)

  • Space Complexity: O(k)

Merge k Sorted Arrays (Variation of #23) - #23#

Input

  • arrays: List of k sorted arrays

Output

  • Single merged sorted array

Example

Input: arrays = [[1,4,5],[1,3,4],[2,6]]
Output: [1,1,2,3,4,4,5,6]
Solution Code 
import heapq

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next
    
    # Required for heapq to compare nodes
    def __lt__(self, other):
        return self.val < other.val

class Solution:
    def mergeKLists(self, lists):
        min_heap = []

        # Initialize heap with the head of each list
        for l in lists:
            if l:
                heapq.heappush(min_heap, l)

        dummy = ListNode()
        current = dummy

        while min_heap:
            # Get the node with the smallest value
            smallest_node = heapq.heappop(min_heap)
            current.next = smallest_node
            current = current.next

            if smallest_node.next:
                heapq.heappush(min_heap, smallest_node.next)

        return dummy.next
Complexity Analysis

  • Time Complexity: O(N log k)

  • Space Complexity: O(k)

class Solution:
    # Python program to find the minimum no. of swaps required to  
    # sort an array by swapping elements to correct positions

    def minSwaps(self,arr):
        
        # Temporary array to store elements in sorted order
        temp = sorted(arr)
        
        # Hashing elements with their correct positions
        pos = {}
        for i in range(len(arr)):
            pos[arr[i]] = i
      
        swaps = 0
        for i in range(len(arr)):
            if temp[i] != arr[i]:
                
                # Index of the element that should be at index i.
                ind = pos[temp[i]]
                arr[i], arr[ind] = arr[ind], arr[i]

                # Update the indices in the dictionary
                pos[arr[i]] = i
                pos[arr[ind]] = ind

                swaps += 1
        return swaps

Median of Two Sorted Arrays - #4#

Input

  • nums1, nums2: Two sorted arrays

Output

  • Median of the merged array

Example

Input: nums1 = [1,3], nums2 = [2]
Output: 2.0
Solution Code 
class Solution:
    def findMedianSortedArrays(self, nums1: List[int], nums2: List[int]) -> float:
        A, B = nums1, nums2
        if len(A) > len(B):
            A, B = B, A
        m, n = len(A), len(B)
        half = (m + n + 1) // 2

        low, high = 0, m
        while low <= high:
            i = (low + high) // 2
            j = half - i
            A_left = A[i - 1] if i > 0 else float('-inf')
            A_right = A[i] if i < m else float('inf')
            B_left = B[j - 1] if j > 0 else float('-inf')
            B_right = B[j] if j < n else float('inf')

            if A_left <= B_right and B_left <= A_right:
                if (m + n) % 2 == 0:
                    return (max(A_left, B_left) + min(A_right, B_right)) / 2.0
                else:
                    return max(A_left, B_left)
            elif A_left > B_right:
                high = i - 1
            else:
                low = i + 1
Complexity Analysis

  • Time Complexity: O(log(min(m, n)))

  • Space Complexity: O(1)

Maximum Product Subarray - #152#

Input

  • nums: List of integers

Output

  • Maximum product of a contiguous subarray

Example

Input: nums = [2,3,-2,4]
Output: 6
Solution Code 
class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        max_prod = min_prod = res = nums[0]
        for num in nums[1:]:
            if num < 0:
                max_prod, min_prod = min_prod, max_prod
            max_prod = max(num, num * max_prod)
            min_prod = min(num, num * min_prod)
            res = max(res, max_prod)
        return res

Burst Balloons - #312#

Input

  • nums: List of balloons (integers)

Output

  • Maximum coins you can collect by bursting balloons

Example

Input: nums = [3,1,5,8]
Output: 167
Solution Code 
class Solution:
    def maxCoins(self, nums: List[int]) -> int:
        nums = [1] + nums + [1]
        n = len(nums)
        dp = [[0] * n for _ in range(n)]

        for length in range(2, n):
            for left in range(0, n - length):
                right = left + length
                for i in range(left + 1, right):
                    dp[left][right] = max(dp[left][right],
                        nums[left] * nums[i] * nums[right] + dp[left][i] + dp[i][right])
        return dp[0][n - 1]
Complexity Analysis

  • Time Complexity: O(n³)

  • Space Complexity: O(n²)

import bisect

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        nums = sorted(set(nums))
        n = len(nums)
        res = float('inf')
        for i in range(n):
            target = nums[i] + len(nums) - 1
            j = bisect.bisect_right(nums, target)

Palindrome Pairs - #336#

Input

  • words: List of strings

Output

  • All valid index pairs (i, j) such that words[i] + words[j] is a palindrome

Example

Input: words = ["abcd","dcba","lls","s","sssll"]
Output: [[0,1],[1,0],[3,2],[2,4]]
Solution Code 
class Solution:
    def palindromePairs(self, words: List[str]) -> List[List[int]]:
        word_map = {word[::-1]: i for i, word in enumerate(words)}
        res = []
        for i, word in enumerate(words):
            for j in range(len(word)+1):
                prefix, suffix = word[:j], word[j:]
                if prefix in word_map and word_map[prefix] != i and suffix == suffix[::-1]:
                    res.append([i, word_map[prefix]])
                if j != len(word) and suffix in word_map and word_map[suffix] != i and prefix == prefix[::-1]:
                    res.append([word_map[suffix], i])
        return res
Complexity Analysis

  • Time Complexity: O(n × k²), where n is number of words, k is max word length

  • Space Complexity: O(n)

Candy - #135#

Input

  • ratings: List of children’s ratings

Output

  • Minimum number of candies to distribute

Example

Input: ratings = [1,0,2]
Output: 5
Solution Code 
class Solution:
    def candy(self, ratings: List[int]) -> int:
        n = len(ratings)
        candies = [1] * n
        for i in range(1, n):
            if ratings[i] > ratings[i-1]:
                candies[i] = candies[i-1] + 1
        for i in range(n-2, -1, -1):
            if ratings[i] > ratings[i+1]:
                candies[i] = max(candies[i], candies[i+1] + 1)
        return sum(candies)
Complexity Analysis

  • Time Complexity: O(n)

  • Space Complexity: O(n)
